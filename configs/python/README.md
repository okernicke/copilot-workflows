# Python Config Readme

This package contains the Python-specific configuration for the agentic workflow.

## What is included

- `global-instructions.md` — Python-specific coding and testing rules.
- `MEMORY.md` — Python-specific project memory, technology details, and conventions.

Shared workflow agents and skills live at the repository root in `agents/` and `skills/`.

## How to use

Install the Python config via `install.ps1 --config python`.

After installation, use the standard VS Code swarm tasks or run the selected Copilot agents directly.
